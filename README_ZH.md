## 核心好玩的特性

* 真正的系统级毛玻璃背景：我们通过 ctypes 桥接了 Windows 底层的 DWM 接口，调用了系统的 Aero Blur 特效。这不是用截图糊弄人的“静态假模糊”，如果启动器后面在放视频或玩游戏，毛玻璃里的画面也是实时变化的，透明感和磨砂感直接拉满。
* 自由的网格与图标排布：你可以像在 Windows 桌面一样，把图标放在网格的任意位置，中间留空也没关系。支持滚轮和方向键左右滑页。
* 拖拽合并文件夹：用鼠标按住一个图标拖到另一个图标上，就能自动合成一个文件夹；把图标拖到文件夹外，就能自动退出来，玩起来非常解压。
* 丝滑的文件夹动画：展开文件夹时，不仅仅是透明度的变化，背后的毛玻璃模糊半径会通过 QPropertyAnimation 在 0.25 秒内从 0 平滑过渡到 25 像素，有一种真实的物理阻尼感。
* 极简的原位重命名：不需要弹出一个丑丑的对话框输入新名字。直接右键或者双击图标下方的文字就可以编辑，写完之后在屏幕空白的地方随手点一下，就会自动保存并退出编辑状态。
* 拼音模糊搜索：集成了拼音库。输入框平时是隐藏的，只要你按下按键打字，它就会自动跳出来，支持中文、英文、拼音首字母和全拼模糊搜索，过滤速度非常快。
* 所见即所得的设置界面：双栏的卡片设置面板，所有的网格行列数、图标尺寸、行间距、列间距，全部可以用滑块拖动调整，主界面会实时跟着你的拖动而重绘，支持设置开机启动和绑定自定义唤出快捷键。
* 纯净的后台运行：我们去掉了右下角系统托盘的图标，让它像系统服务一样安静。使用默认的 Ctrl + Space（可自定义）一键唤出或隐藏。想要修改设置或者完全退出？在启动器界面的任意空白地方右击鼠标，就能弹出菜单。

## 项目的各个文件夹是干嘛的

整个项目的代码结构非常清晰，被我分成了几个不同的功能模块：

```
MacLaunchpad/
├── core/                       # 核心业务逻辑与 Windows 系统接口的对接
│   ├── __init__.py
│   ├── app_scanner.py          # 数据层：负责读写本地应用 JSON 列表，管理文件夹的嵌套逻辑和启动应用进程
│   ├── config.py               # 配置管理：负责 config.json 的持久化，以及用 winreg 修改注册表实现自启动
│   ├── hotkey_manager.py       # 快捷键监听：用 RegisterHotKey 在后台线程单独跑消息循环，保证按键检测不卡 UI
│   ├── icon_cache.py           # 图标缓存：把提取出的图标变成 PNG 存起来，校验文件修改时间，防止重复提取卡顿
│   └── icon_extractor.py       # 图标提取：调用 Win32 PrivateExtractIcons 提取 EXE 内部的无损高清图标数据
├── data/                       # 本地数据库目录
│   └── apps_db.json            # 里面存着你拖进来的应用路径、网格位置参数以及文件夹分组
├── docs/                       # 存放项目规格和开发参考说明文档
├── ui/                         # 用 PyQt5 写的界面小组件
│   ├── __init__.py
│   ├── animations.py           # 负责背景淡入、图标依次缩放跳动、切页滑动等各种动画的逻辑
│   ├── app_grid.py             # 网格容器：计算行列坐标，处理鼠标拖拽重排、交换和合并的操作
│   ├── app_icon.py             # 单个图标：处理悬停缩放、右键菜单、就地文字重命名输入框的绘制
│   ├── blur_effect.py          # 核心玻璃渲染：调用 SetWindowCompositionAttribute 开启磨砂玻璃
│   ├── folder_view.py          # 文件夹弹出框：控制文件夹卡片和背景模糊 radius 的渐变动画
│   ├── launchpad_window.py     # 主窗口：承载所有组件，处理全屏置顶、滚轮事件、空白处点击失焦和拖入外部文件
│   ├── page_indicator.py       # 底部页码指示器：画几个小圆点，随翻页平滑切换高亮
│   ├── search_bar.py           # 顶部搜索栏：输入文字时动态向外发送过滤字符的信号
│   └── settings_window.py      # 设置窗口：画出 iOS 风格的滑动开关和滑块，调整数值后发送重排信号
├── main.py                     # 程序总入口（设置高DPI自适应，通过 Mutex 防止多开，初始化 app）
└── requirements.txt            # 项目需要的第三方包
```

## 各个文件的具体运行逻辑

### 核心处理逻辑 (core/)

* **`app_scanner.py`**：这是项目的数据大管家。为了保证性能，我们不搞全盘扫描，而是让用户自己把软件或快捷方式拖进来。它负责算好每个图标的 index，还要处理非常微妙的文件夹逻辑——比如把一个图标拖走时，要确保清理掉它原本在文件夹里的 id，不能让它同时出现在文件夹里又出现在桌面上（之前我们因为这个出过不少“分身幽灵图标”的 Bug）。
* **`config.py`**：配置中心。把快捷键、网格行列等用户喜好保存在 `%APPDATA%/MacLaunchpad/config.json` 里。里面还包了一层 `winreg` 注册表操作，开机自启动开关就是通过它写入 Windows 启动注册表的。
* **`hotkey_manager.py`**：系统全局热键监听。因为键盘监听是全局的，如果直接写在主界面里，只要界面一卡按键就会失灵。所以这里开了一个后台线程，在里面调用 Win32 原生的 `GetMessageW` 循环，一旦听到 Ctrl+Space 就把消息抛回给主线程，十分灵敏。
* **`icon_extractor.py`**：提取图标的法宝。Windows 上的 EXE 图标提取很容易糊，这个文件调用底层的 `PrivateExtractIconsW`，尽可能榨干 EXE 里的超清（比如 256x256）位图数据，如果实在找不到才用常规接口兜底。
* **`icon_cache.py`**：为了不让程序每次冷启动都去重复提取几百个 EXE 的图标，这里把提出来的图标存为 PNG 图片放到本地缓存目录。每次启动前只要对一下 EXE 的修改时间（mtime），没变过就直接拿来用，速度飞快。

### 图形界面逻辑 (ui/)

* **`launchpad_window.py`**：整个程序的主画板。它负责实现全屏无边框，而且为了防止 DWM 毛玻璃和 Qt 的透明图层冲突导致出现灰色实心背景，我们在 `paintEvent` 里面强行画了一个几乎看不见（1/255 透明度）的底色去阻断系统的默认绘制。它还负责接收文件拖入，检测到有文件拖进来就把它转给 `app_scanner`。
* **`blur_effect.py`**：控制窗口磨砂玻璃效果。我们试过很多种 Win11 的 Acrylic 模糊接口，但微软的设定会让背景有一层极度死板的灰黑蒙版，所以在反复对比后，这里依然使用了经典的 `ACCENT_ENABLE_BLURBEHIND`，以保证最清爽、透明度直接拉满的磨砂玻璃感。
* **`app_grid.py` & `app_icon.py`**：网格和图标。负责最核心的图标绘制。为了防止拖拽图标时，图标的左上角瞬间跳到鼠标指针上（这种跳跃很生硬），我们在这里计算了鼠标点击图标时的相对偏移量，让拖拽虚像完全跟着鼠标手感走。
* **`folder_view.py`**：文件夹展开效果。我们没有让它像其他启动器那样撑满全屏，而是做了一个居中的圆角模糊框，点击外面就会像按下 Esc 键一样顺滑合上。
* **`settings_window.py`**：设置窗口。我们手画了一个仿 iOS 的 Toggle 开关，并且把滑块和数值绑定。所有你调过的行列网格、图标大小，在你松开鼠标的一瞬间都会通过信号刷新主窗口的布局，非常解压。

## 怎么在你的电脑上运行起来

### 环境要求

需要你的电脑安装了 **Python 3.8 或以上版本**。

### 安装需要的依赖

在项目目录下打开终端，输入以下命令安装所需的 Win32 接口包装和 UI 库：

```bash
pip install -r requirements.txt
```

依赖包主要是：

* `PyQt5`（做界面的骨架）
* `pywin32`（对接 Windows 底层接口）
* `Pillow`（处理图标转换）
* `pypinyin`（支持拼音搜索过滤）
* `keyboard`（处理全局按键绑定）

### 启动程序

装好依赖后，直接在终端里敲这一行命令就可以跑起来啦：

```bash
python main.py
```

*注意：如果程序已经在后台跑着了，双击 main.py 会静默退出，不会多开冲突。你可以按 Ctrl + Space 试试看能不能唤出它！*

## 怎么玩转它（使用指南）

* **唤出与收起**：按下全局快捷键 `Ctrl + Space` 就能唤出或隐藏它。唤出后，按 `Esc` 键，或者随便点一下图标以外的空白背景，它就会自己滑下去。
* **自由摆放与合并**：按住一个图标拖拽，拖到另一个图标上面并重叠，保持一会儿就会**创建文件夹**。直接拖入空白格子可以**重排位置**；在打开的文件夹中把图标拖到框外，就能**移出文件夹**。
* **修改名字与删除**：对任意图标右击，在菜单中选择重命名（双击名字也可以），输入新名字后点击外面空白处就能直接保存。选择删除就可以把它从启动器里去掉。
* **添加你的软件**：直接从 Windows 资源管理器里，把你想加进来的 EXE 程序或者快捷方式（.lnk）拖拽进 Launchpad 的全屏界面里，松开鼠标就会自动加入并生成图标。
* **调整参数**：在界面的空白地方右击鼠标，选择 **“设置...”** 就可以打开设置面板。你可以随便调大图标、拉开图标的间距、甚至改掉默认的 Ctrl + Space 快捷键。
* **退出程序**：不想用了？在空白处右击鼠标，选择 **“完全退出”**，就会杀掉后台消息循环，彻底退出程序。
